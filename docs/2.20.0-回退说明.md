# Kimi Code Android 2.20.0 — 撤掉原生首页，回到网页版

## 这版做了什么

1. **原生首页整套删掉**。DSH 风格那套「会话 / 运行 / 设置」不再存在，启动入口回到
   网页工作台外壳（底部五个标签：首页 / 插件 / 设置 / 数据 / 终端）。
2. **手机操控入口搬到「设置」页顶部**，一眼能看到开没开。
3. **MCP 接线跟着搬了过来**。原来这段挂在首页的 `onCreate` 里，首页删掉后
   模型那边会一个 `phone_*` 工具都看不到——现在改成引擎每次就绪后写一次。
4. **「自动进入工作台」开关恢复生效**（默认关）。想要「打开就是工作台」，
   去设置里勾一下；不勾就还是原来「点进入工作台」的节奏。

## 为什么撤

- 底栏文字贴着屏幕边缘、卡片基线对不齐，观感确实不行；
- 第二次启动进不去；
- 这套壳是自己用代码一行行搭的，修排版要重写一遍布局，收益不如把网页工作台做厚。

原生首页相关的 `HomeActivity.kt`、`SessionRepository.kt` 已经删除，
`DshUi/DshIcon` 只留给「手机操控」这一页用。

## 手机操控怎么开

1. 打开 App → 底部「设置」→ 最上面那张「手机操控」卡片；
2. 点「去系统设置开启」→ 无障碍 → 已下载的服务 → **Kimi Code 手机操控** → 开启；
3. 回到 App，卡片变成绿色「已开启」，点进去可以「读取当前屏幕」自检；
4. 以后在对话框里直接说人话就行，例如：
   - 「打开微信，找到张三，发一句我晚点到」
   - 「把当前页面的地址复制下来」
   - 「帮我点外卖，选昨天那家」

## 模型能用的 13 个工具

| 工具 | 作用 |
| --- | --- |
| `phone_screen` | 读当前屏幕的文字与控件（带坐标、是否可点） |
| `phone_tap` | 按文字点，比坐标稳 |
| `phone_tap_xy` | 按坐标点 |
| `phone_long_press` | **新增**：长按（长按菜单、拖动前按住） |
| `phone_type` | 往焦点输入框写文字 |
| `phone_scroll` | 上下滚动 |
| `phone_swipe` | 两点之间滑动 |
| `phone_key` | 返回 / 桌面 / 多任务 / 通知栏 |
| `phone_open` | 按应用名或包名打开 App |
| `phone_apps` | 列出已安装 App |
| `phone_clipboard` | 读写剪贴板 |
| `phone_screenshot` | 截屏（Android 11+） |
| `phone_wait` | **新增**：等某段文字出现再继续，最多 30 秒 |

## 边界（写在明面上）

- 只能看到**当前屏幕上显示的内容**，读不到 App 内部数据；
- 银行、支付类页面通常禁止截屏/读屏，这是系统限制，不是 App 的问题；
- 每一次操作都会写进「首页 → 日志」，随时可以关掉无障碍开关；
- 模型拿到的是当前这一步的屏幕文字，不会后台录制。
