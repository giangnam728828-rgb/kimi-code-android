# Kimi Code Android 2.19.1 — 白屏闪退修复

## 症状

装完 2.19.0，点图标：**先白一下，然后直接退回桌面**，没有任何提示。
每次都这样，不是偶发。

## 根因

不是环境没装好，也不是权限，是**首页代码里一个必崩的空指针**。

2.19.0 的原生首页用 Canvas 自己画图标，`DshIcon.view()` 每调一次就 `new` 一个 `IconView` 返回。
这个 View 刚创建、还没被 `addView` 过，`view.layoutParams` 是 **null**。
而当时的写法是：

```kotlin
addView(glyph, FrameLayout.LayoutParams(glyph.layoutParams))
```

`FrameLayout.LayoutParams(ViewGroup.LayoutParams source)` 这个构造函数，第一行就是读
`source.width` —— 传 null 进去当场 `NullPointerException`。

崩的顺序：

1. `HomeActivity.onCreate()` → `buildNavBar()` → 底部导航第一个图标 → **NPE**；
2. 就算这一步跳过，`selectTab(0)` → `buildChatsPage()` → 搜索框的放大镜图标
   （`DshUi.withSearchIcon`）→ 同一个 NPE；
3. 设置页的头像图标、导航栏重绘，全都是同一个写法。

一共 **6 处**，全是启动必经路径。所以是「一开就崩」，白屏就是主题背景色还没被首页盖住的那一帧。

## 修了什么

| 位置 | 改动 |
| --- | --- |
| `DshUi.kt` | 新增 `centerParams()`，返回固定的 `WRAP_CONTENT × WRAP_CONTENT` + 居中；3 处图标改用它 |
| `HomeActivity.kt` | 3 处同样的写法改掉（导航栏 2 处、设置页头像 1 处） |

图标本来就在 `onMeasure` 里按 `sizeDp` 自己定尺寸，不依赖外部参数，所以换成
`WRAP_CONTENT` 后大小完全不变。

## 顺手加的兜底（防止下次又是白屏，什么都拿不到）

1. **崩溃落盘**：`CrashGuard` 接管未捕获异常，把时间、页面、机型、完整堆栈写进私有目录，
   再交回系统；
2. **下次启动红条**：会话页顶部出现一条红色提示「上次启动崩了一次 · 点这里复制日志」，
   点一下整段堆栈进剪贴板，直接粘贴发出来即可，不用连电脑抓 logcat；
3. **自动降级**：首页构建如果还是抛异常，不再白屏退出，而是记录堆栈后直接跳进
   **网页版工作台**（功能完整），并提示「已切到网页版」。

## 装完请这样验

1. 点开 App，应当直接看到浅紫灰底的原生首页 + 底部三个页签（会话 / 运行 / 设置），**不再闪退**；
2. 点左下角菜单键，抽屉从左边滑出，能看到会话和文件夹；
3. 点右上角笔，进网页版工作台聊天；
4. 如果还是闪退：重新打开 App，会话页顶部会有红色崩溃条，点一下复制，把内容发我。
