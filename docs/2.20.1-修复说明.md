# Kimi Code Android 2.20.1 修复说明

## 这次修的是什么

**问题**：点底部「设置」→ 进入设置页 → 按返回，App 直接跳进网页工作台，回不到原来的首页。

**根因**：设置页是一个独立的 Activity。返回时主界面会走 `onResume → render()`，而 `render()` 里每次都重新读了一次「自动进入工作台」开关：

```kotlin
if (pendingOpenWeb || Prefs.autoEnter(this)) {
    if (Runtime.phase == READY) openWorkspace()
}
```

只要这个开关是开着的（或者启动时带的「打开工作台」标记还没被消费掉），任何一次回到前台都会被当成「该进工作台了」——包括从设置页返回。所以表现就是「点设置、再返回，人已经在工作台里了」。

**修复**：
1. 开关只在 **冷启动那一刻** 读一次，放进 `launchAutoEnter`；进入工作台后立刻清空，不再每次 `onResume` 重新判断。
2. 只要用户主动切页（设置 / 插件 / 数据 / 终端），就取消待进入标记——人已经明确离开首页了，不该再被自动带走。
3. 打开设置页之前也清一次，作为双保险。

修完之后的行为：
- 从设置页返回 → 回到你进来时的那个页面（首页还是首页）；
- 如果你开了「自动进入工作台」，只有 **重新冷启动 App** 时才会自动进一次，不会再在页面间乱跳；
- 不想启动就进工作台，去设置里把那个开关关掉即可。
