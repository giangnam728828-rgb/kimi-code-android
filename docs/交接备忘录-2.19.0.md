# Kimi Code Android 2.19.0 交接备忘录

> 这版是一次 **UI 层重做**：把原来「启动面板 + 五个底部页签 + 进入工作台」换成
> DSH-Go 那样的原生首页（会话 / 运行 / 设置 + 侧边抽屉），并补上手机操控。
> 底层 kimi-cli、rootfs、聊天渲染一行没动。

---

## 一、先说清楚：抄了什么，没抄什么

用户给的参考是 [ccch1mneyyy/dsh-Go](https://github.com/ccch1mneyyy/dsh-Go)，21.5k star，
**Dart / Flutter，AGPL-3.0**。

- **没有复制它的任何一行代码。** AGPL-3.0 与本项目的 MIT 不兼容，贴进来会污染整个仓库的授权。
- 参考的是**信息架构与交互**：页面怎么分、抽屉里放什么、设置怎么分组、原生与网页怎么切。
- Swift/Flutter 的实现方式（Riverpod、GlassSurface、Squircle）也没有照搬——本项目没有
  androidx、没有 Compose、没有图标库，全部平台 View + Canvas 重写。

它的实现结论（调研记录，供后续参考）：

| 维度 | DSH-Go 的做法 |
|---|---|
| 原生 / 网页切换 | `state/ui_mode_state.dart`：SharedPreferences 存 `ui.mode`，`ModeHome` 用 AnimatedSwitcher 在 `HomeShell` 与 `WebHome` 间切；切到网页时把当前会话 ID 带过去 |
| 抽屉 | `ui/shell/sessions_drawer.dart`（43KB）：品牌行 + 模式键 + 网页键 + 新对话；搜索框；工作区切换；筛选胶囊（全部/运行中/待确认/未读）；文件夹；按 今天/本周/更早 分组；底部 IdentityBar（本机状态 + 插件 + 设置） |
| 会话行 | 44dp 高，标题缩进 20dp，末尾一个标记：待确认 / 运行中转圈 / 未读点 |
| 设置 | 六个分组：AI、能力、外观、通用、主机、帮助；行高 52dp，左侧彩色圆角图标 |
| 手机操控 | Flutter ↔ Kotlin Platform Channel；`PhoneControl.kt`（59KB）+ `PhoneCore.kt`（83KB）+ 无障碍服务；对模型暴露成 **MCP**（`McpServer.kt`），固定 14 个工具：apps / open / intent / notify / clipboard / screen / collect / tap / type / scroll / key / tap_xy / handoff / android_shell |
| 安全 | `SafetyGate.kt`（25KB）、敏感词、确认方式、不打扰模式（需 Shizuku/ADB） |

## 二、这一版做了什么

### 2.1 原生首页（新文件 `HomeActivity.kt`，约 900 行）

- **launcher 换成 HomeActivity**，MainActivity 退到第二层（工作台 / 数据 / 终端 / 插件）。
- 三个页签：
  - **会话**：顶栏（圆形菜单键 + 标题卡「会话 / 本机 · 运行中」+ 新建笔）、搜索、四个筛选胶囊、按 今天/本周/更早 分组的会话列表（白卡承托）。
  - **运行**：状态卡（圆点 + 标题 + 端口/已运行/工作目录）、启动/重启/停止/打开工作台、最近 18 行日志。
  - **设置**：账户概览卡（本机引擎 + 版本 + 端口）、AI（模型 / 权限 / 个性化）、能力（手机操控 / 联网搜索 / 图像与视频）、通用（界面 / 数据备份 / 终端 / 插件）、关于（网页版工作台 / 版本）。
- **抽屉**：86% 宽、右侧圆角 26、品牌行 + 原生/网页切换键 + 关闭键、新对话、搜索、筛选、按工作区分组的会话、底部「本机 运行中 + 插件 + 设置」。
- 会话数据：`SessionRepository.kt` 直接读 `GET /api/v1/sessions` 与 `GET /api/v1/workspaces`（本机 127.0.0.1，带 `server.token`），失败重试 3 次（服务刚 READY 时 token 还没落盘）。
- 点会话：`Intent` 带 `session_id` / `session_title` 进 MainActivity；页面加载完成后注入脚本，点开网页自己的会话 sheet 并按标题点那一行。**best effort**：找不到（会话在别的工作区）就停在工作台，不报错、不丢东西。

### 2.2 视觉层（`DshUi.kt` + `DshIcon.kt`，约 700 行）

- 色板：`#F8F7FC → #EEEEF7` 渐变底、白色半透明卡（`#FCFFFFFF` + `#F0F0F7` 细边）、主色 `#4F5BD5`、文字 `#14141B / #6E6E7A / #9A9AA6`。
- 组件：玻璃卡、圆形图标键、胶囊按钮、筛选 chip、设置行（34dp 彩色圆角图标 + 标签 + 值 + 箭头）、会话行（状态点 + 标题 + 副标题 + 待确认）。
- 图标：24 个线条图标全部 Canvas 手绘（菜单、加号、搜索、会话、运行、设置、返回、箭头、更多、切换、文件夹、插件、手机、地球、图片、模型、盾牌、人、终端、数据、关闭、编辑、停止、刷新），**没有引入任何图标库或新依赖**。

### 2.3 原生 / 网页双界面

- 抽屉右上角的切换键 → 直接进 MainActivity 的完整工作台（等价于 DSH 的 `WebModeKey`）。
- 设置 → 通用 → 界面 → 选「网页版工作台」。
- **没有做** DSH 那种「切换后停在同一个会话」：Kimi 的 dist-web 不把当前会话写进 URL，也没有持久化接口，切换只能回到工作台首页。这一点在第三节的已知限制里写清楚了。

### 2.4 手机操控（新文件 4 个 + 1 个 JS）

链路：

```
模型
 └─ MCP 工具 phone_screen / phone_tap / ...
     └─ /opt/kimi/bin/phone-mcp.js（容器内，stdio MCP）
         └─ POST http://127.0.0.1:<port>/phone/<tool>   ← 只绑本机 + X-Phone-Token
             └─ PhoneBridge.kt（App 内 HTTP 桥）
                 └─ PhoneAccessibilityService.kt（无障碍）
                     └─ 读屏 / 点按 / 输入 / 滚动 / 全局键 / 打开 App / 剪贴板 / 截图
```

- `PhoneAccessibilityService.kt`：`rootInActiveWindow` 遍历成「文字 @(x,y)」的扁平文本（最多 120 个控件）；按文字找节点 → 可点祖先 → 坐标兜底；`dispatchGesture` 做点按/长按/滑动；`ACTION_SET_TEXT` 输入；`GLOBAL_ACTION_*` 返回/桌面/多任务；`takeScreenshot`（Android 11+）。
- `PhoneBridge.kt`：`ServerSocket(0, 16, 127.0.0.1)`，每个请求校验 token，JSON 进出。
- `phone-mcp.js`：11 个工具（screen / tap / tap_xy / type / scroll / key / open / apps / clipboard / screenshot / swipe），schema 带中文描述。
- `PhoneAccess.kt`：无障碍状态检测、token、起桥、把脚本 + `phone.json` + `mcp.json` 写进 rootfs。
- `PhoneControlActivity.kt`：开关引导（跳系统无障碍设置）、能力说明、边界说明、读屏自检。
- 配置写入 `rootfs/root/.kimi-code/mcp.json`，格式：
  ```json
  {"mcpServers":{"phone":{"transport":"stdio","command":"/opt/node/bin/node",
    "args":["/opt/kimi/bin/phone-mcp.js"],"enabled":true,"toolTimeoutMs":20000}}}
  ```

**和 DSH 的差距（如实说）**：它还有 intent（闹钟/日历/短信草稿/导航）、通知读取、跨 App 采集、任务编排、安全门与「不打扰模式」。我们这版只有基础操作闭环，够「自己动手点」，但没有它的任务级编排。

## 三、已知限制（真机验收前先看）

1. **会话定位是 best effort**。dist-web 移动端没有 URL 深链，当前会话只在内存里。点会话 → 注入脚本打开 sheet 点标题；如果该会话属于别的工作区，或标题重复，可能点不中，此时停在工作台，用户自己点一下。**没有数据风险**。
2. **切换原生/网页不会停在同一个会话**（原因同上）。
3. **MCP 注册要重启引擎**。`mcp.json` 是服务启动时读的；第一次开启手机操控后，到「运行 → 重启」一次，模型才看得到 `phone_*` 工具。
4. **无障碍必须手动开**。Android 硬性规定，App 不能代劳。路径：设置 → 无障碍 → 已下载的服务 → Kimi Code 手机操控。
5. **截图要 Android 11+**；银行/支付页禁止截屏，属系统限制。
6. 抽屉里的「文件夹」目前按**工作区**分组，不是 DSH 那种可新建的自定义文件夹。
7. 本地 `assembleRelease` 用的是 debug key（正式 key 只在 CI secrets 里），**本地包不能覆盖安装**，必须用 CI 产物。

## 六、构建与发布

```bash
cd android
JAVA_HOME=<jdk> ANDROID_HOME=/opt/android-sdk \
  <gradle-8.14.3>/bin/gradle :app:assembleRelease
```

- 不要用 `./gradlew`（wrapper 下载发行包会超时）。
- 单测：`:app:testReleaseUnitTest`，当前 114 个全绿。
- CI：`.github/workflows/build-apk.yml`，push main 触发；三个 job（verify-runtime → build → release），
  Release tag 固定 `rootfs-v1`，APK 覆盖同名 asset。
- 正式签名在 CI secrets：`KEYSTORE_BASE64 / KEYSTORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD`。
  证书 SHA-256 `26902ef6…fe163a`，与 2.14.0–2.18.1 同一张，可直接覆盖。
